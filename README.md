# UD5_T2
Una página para la tarea UD5 T2 de la asignatura de PRO

Añadimos 3 funciones que son: añadir, mostrar y eliminar.

Luego añadi 4 clases: un menu que es mi app, como dato elegi hacer un plato de comida, como operaciones que puedan hacer escogi ServicioPlato y como validaciones escogi ValidacionesPlato.

Y como datos escogi nombre del plato, tipo de plato, precio del plato y una puntación del 1 al 5 del plato.
